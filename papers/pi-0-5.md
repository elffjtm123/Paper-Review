## 한 줄 요약
웹 VQA·고수준 하위 작업 예측·이종 로봇 데이터를 공동 학습해 한 번도 본 적 없는 가정집에서도 장거리 청소 작업을 수행하는 오픈월드 VLA.

## 핵심 메커니즘
- 사전학습 단계에서 FAST 이산 액션과 웹/언어/바운딩박스/하위 작업(subtask) 데이터를 함께 co-training.
- 추론 시 먼저 자연어로 현재 하위 작업을 예측(High-level)하고, 그에 조건화해 Flow Matching Action Expert로 연속 행동(Low-level) 생성.
- 단일 모델 안에서 의미 추론·계획·저수준 제어를 계층적으로 통합.

## 기존 대비 차이
π0가 주로 익숙한 환경의 정밀 조작에 강했다면, π0.5는 이종 데이터 공동학습과 계층적 서브태스크 추론으로 완전히 새로운 환경 일반화를 달성.

## 한계 & 연결
Heart-Lab LIBERO 재현 96.35%로 클린 성능은 최상위이나, 가우시안 블러 등 시각 센서 노이즈에서는 성능이 유의미하게 하락(98.2→89.9%).
